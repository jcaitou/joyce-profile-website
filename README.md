# Ryan Lo

A beginner-friendly Next.js copy of [ryanlo.ca](https://www.ryanlo.ca/). Pages live in `app/`, shared pieces live in `components/`, and the project list is `data/projects.js`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy with the Vercel CLI:

```bash
npx vercel
```

Or import the project from Git on [vercel.com](https://vercel.com). A normal Next.js app is enough — no extra Vercel config.
